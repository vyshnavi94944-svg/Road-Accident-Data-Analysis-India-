# Stage 3 – Data Extraction

## Purpose

Extract the important fields and records required for road accident analysis from the selected dataset before validation, cleaning and aggregation.

## Required checks

- Load the selected road accident data.
- Identify the important fields required for analysis.
- Extract accident-related information from the dataset.
- Extract year-wise accident records.
- Extract accident severity information.
- Extract accident cause information.
- Extract vehicle-type information.
- Extract speed-limit related information.
- Extract alcohol and pedestrian involvement information.
- Extract daylight-related accident information.
- Check the extracted data for completeness.
- Prepare the extracted data for validation and cleaning.

**Important:** The notebook uses the actual data selected from the previous stage. Required fields and records are extracted from the available dataset rather than being manually created.

## Output

The stage produces the extracted accident-related fields and records required for data validation, cleaning, aggregation and analysis in the following project stages.
