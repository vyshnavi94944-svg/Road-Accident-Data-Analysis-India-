# Stage 5 – Data Aggregation

## Purpose

Aggregate the cleaned road accident data into meaningful summaries that can be used for comparison, analysis and visualization.

## Required checks

- Load the cleaned road accident dataset.
- Group accident records by year.
- Calculate accident counts for relevant categories.
- Aggregate fatalities by state.
- Aggregate severe injuries by state.
- Aggregate minor injuries by state.
- Calculate total injuries where required.
- Prepare state-wise accident summaries.
- Prepare accident and fatality summaries for comparison.
- Sort aggregated results for meaningful representation.
- Save the required aggregated data for the following analysis stages.

**Important:** The aggregation is performed using the actual cleaned dataset. Counts, sums and other aggregated values are calculated from the available records rather than being manually entered.

## Output

The stage produces aggregated road accident data containing meaningful summaries of accidents, fatalities and injuries that can be used for further analysis and visualization.
