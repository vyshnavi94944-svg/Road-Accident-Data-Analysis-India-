# Stage 2 – Data Acquisition

## Purpose

Select and filter the required road accident records and fields from the loaded dataset before data extraction, validation and cleaning.

## Required checks

- Work with the dataset loaded from `india_road_accidents.csv`.
- Identify the columns required for the project analysis.
- Select the relevant accident-related columns.
- Filter records based on the required accident categories.
- Examine year-wise accident records.
- Check relevant accident severity categories.
- Check relevant accident cause categories.
- Check vehicle-type categories.
- Check speed-limit related records.
- Check alcohol and pedestrian involvement where available.
- Check daylight-related accident records.
- Verify that the selected and filtered data is suitable for the next stage.

**Important:** The notebook uses the actual dataset loaded from the CSV file. Filtering and selection are performed using the available values in the dataset rather than using hard-coded records.

## Output

The stage produces the required accident records and selected fields that can be used for data extraction, validation and cleaning in the following project stages.
