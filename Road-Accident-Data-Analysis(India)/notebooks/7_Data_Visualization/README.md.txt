# Stage 7 – Data Visualization

## Purpose

Create visual representations of the analyzed road accident data to make accident patterns, distributions and relationships easier to understand.

## Required checks

- Load the aggregated and analyzed road accident data.
- Create a visualization of accidents by state.
- Create a visualization of accident distribution by state.
- Create a visualization of fatalities by state.
- Create a comparison of accidents versus fatalities.
- Create an accident distribution visualization.
- Create a distribution of fatalities visualization.
- Create a visualization of severe and minor injuries by state.
- Create a comparison of accidents versus total injuries.
- Add appropriate titles, labels and axes to the visualizations.
- Save the generated visualizations in the project output directory.

**Important:** The visualizations are generated from the actual analyzed and aggregated dataset. Values are calculated from the project data rather than being manually entered.

## Output

The stage produces visualizations showing accident counts, fatalities, injuries, distributions and relationships between accident-related variables.

The generated visualizations are stored in:

`outputs/visualizations/`
