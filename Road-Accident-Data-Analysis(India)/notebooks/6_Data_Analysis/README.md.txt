# Stage 6 – Data Analysis

## Purpose

Analyze the aggregated road accident data to identify patterns, trends and relationships between accidents, fatalities and injuries.

## Required checks

- Load the aggregated road accident dataset.
- Analyze accident counts by state.
- Analyze fatalities by state.
- Analyze severe and minor injuries by state.
- Analyze total injuries by state.
- Compare accident counts with fatalities.
- Compare accident counts with total injuries.
- Examine accident distributions across states.
- Calculate relevant summary statistics.
- Identify important patterns and relationships in the aggregated data.
- Prepare the results required for data visualization and interpretation.

**Important:** The analysis is performed using the actual aggregated data generated from the project dataset. Results are calculated from the available records rather than being manually entered.

## Output

The stage produces statistical summaries, comparisons and analytical results that can be used for visualization and results interpretation in the following project stages.
